## 📘 Overview  
**Sazon Food App** is a mobile application built using **Java** in **Android Studio** for the frontend, with **Firebase** handling the backend services. Designed to provide a smooth and convenient food ordering experience, the app allows users to sign up, browse menus, manage favorites and cart items, and personalize their profile—all through an intuitive interface.

---

## 🧰 Technologies Used  
- **Java** – Powers the frontend interface and user interactions  
- **Firebase** – Provides real-time database, authentication, and cloud storage support

---

## 🚀 Features

### 🔐 User Authentication  
- **Register** – Create an account using a valid email and password  
- **Login** – Access the app with secure user authentication  

---

### 🏠 Home Page  
- **Search Bar** – Search for desired food items directly from the homepage  
- **Popular Items** – Browse trending dishes; tap to view detailed information  
- **Categories** – Explore items based on food categories (e.g., Snacks, Beverages, Desserts)

---

### 🍲 Description Pages  
- **Popular Items Details** – Shows food image, description, and options to add to **Cart** or **Favorites**  
- **Category Items** – Clicking a category displays all related dishes with individual description pages

---

### ❤️ Favorites  
- Save your favorite dishes for quick access  
- View, manage, or remove items as needed

---

### 🛒 Cart  
- Add food items for checkout  
- Edit quantity or remove items directly from the cart

---

### 👤 Profile Page  
- Update personal credentials (e.g., name, email, password)  
- Manage account preferences

---

### 🔎 Search Page  
- Quickly locate specific food items  
- Displays real-time results and fallback for unavailable items

---

**Sazon Food App** delivers a streamlined food browsing experience with essential features like secure login, smart search, dynamic product listings, and personalized user interactions.
